# Carpeta docs

Esta carpeta se creó para contener documentación y recursos del proyecto, como el diagrama de arquitectura, documentación adicional, ejemplos de docker-compose, y guías de despliegue.

Archivos sugeridos:
- `architecture.png` — Diagrama de arquitectura (coloca aquí la imagen que compartiste).
- `README.md` — Documentación extendida del proyecto.
- `docker-compose.example.yml` — Ejemplo de docker-compose para levantar la infraestructura (Kafka, Zookeeper, bases de datos, config-server, eureka, gateway).

Instrucciones:
1. Sube la imagen del diagrama a `docs/architecture.png`.
2. Si quieres, puedo generar un `docker-compose.example.yml` y colocarlo aquí para que lo revises.
